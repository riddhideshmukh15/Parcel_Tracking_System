# 📦 Parcel Tracking System

A simple **Python-based Parcel Tracking System** that allows users to add parcels, view parcel details, and track parcels using a unique tracking ID.

## 🚀 Features

* Add a new parcel
* Generate a unique tracking ID
* View all parcels
* Track a parcel using its tracking ID
* Display sender, receiver, address, and parcel status
* Simple menu-driven interface

## 🛠️ Technologies Used

* Python
* Dictionaries
* Loops
* Conditional statements
* User input

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/riddhideshmukh15/Parcel_Tracking_System.git
   ```

2. Open the project folder:

   ```bash
   cd Parcel_Tracking_System
   ```

3. Run the Python file:

   ```bash
   python parcel_tracking.py
   ```
