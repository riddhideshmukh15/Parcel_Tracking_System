# 📦 Parcel Tracking System

A simple **Python-based Parcel Tracking System** that allows users to add parcels, view all parcels, track delivery progress, and update parcel status.

## Features

* Add a new parcel
* Automatically generate a tracking ID
* View all parcels
* Track the delivery progress of a specific parcel
* Update parcel status
* Handle invalid tracking IDs and choices
* Simple menu-driven interface

## Technologies Used

* Python
* Dictionaries
* Loops
* Conditional Statements
* User Input

## How to Run

Run the following command:

```bash
python parcel_tracking.py
```

## Parcel Status

The parcel can have the following statuses:

* Booked
* In Transit
* Out for Delivery
* Delivered
